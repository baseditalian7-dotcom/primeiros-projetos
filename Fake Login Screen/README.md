# Fake Login Screen

Projeto simples de tela de login fake com HTML, CSS e JavaScript.

## Funcionalidades

- Layout simples e responsivo
- Validação básica de e-mail
- Validação básica de senha
- Usuário fake cadastrado no JavaScript
- Mensagens de erro por campo
- Botão para mostrar ou esconder a senha
- Opção de lembrar e-mail
- Sessão fake salva no LocalStorage
- Botão de sair da sessão fake

## Usuário fake

```text
E-mail: lucas@email.com
Senha: 123456
```
