# Primeiros Projetos

Esta pasta reúne projetos simples para praticar fundamentos de programação, frontend e backend.

Cada projeto fica em sua própria pasta, com README, frontend organizado e um backend pequeno para estudo.

## Projetos

### 1. Basic Calculator

Calculadora básica com:

- HTML
- CSS
- JavaScript
- Mini backend em Python

Funcionalidades:

- Soma
- Subtração
- Multiplicação
- Divisão

Pasta:

```text
Basic Calculator/
```

### 2. Digital Clock

Relógio digital com:

- HTML
- CSS
- JavaScript
- Mini backend em Java

Funcionalidades:

- Horário em tempo real
- Atualização automática a cada segundo
- Data atual
- Dia da semana
- Seleção entre 4 fusos horários

Pasta:

```text
Digital Clock/
```

## Objetivo

O objetivo dessa coleção é evoluir aos poucos, criando projetos pequenos, organizados e fáceis de explicar no GitHub.
